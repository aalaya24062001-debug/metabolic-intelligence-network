# Maternal-Fetal Metabolic Intelligence Network

An interactive R Shiny application built with `bslib`, `plotly`, and dynamic predictive modeling (Logit-Linear vs. Auto-ARIMA) for tracking maternal-fetal metabolic prevalence across international cohorts.

## Features
- Dynamic prevalence tracking across longitudinal data
- Interactive visualizations via Plotly
- Model-switching analytics engine
- Deployed on shinyapps.io
